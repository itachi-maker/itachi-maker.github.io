📘 Guía Rápida de Ejecución

  • Sin Root (Brevent / Shizuku): Abre tu terminal de mandos (Exec Command en Brevent o LADB) y pega el comando de la sección correspondiente.
  • Con Root (KernelSU / Magisk): Ejecuta los comandos desde tu consola con permisos superusuario (`su`).
  • Seguridad: Todos los cambios en parámetros del sistema son temporales y se pueden revertir reiniciando el teléfono.

⚡ 1. RESPUESTA TÁCTIL Y PANTALLA

Sin Root / Brevent

Reducción de Latencia de Toque (Touch Lag Zero)

Reduce el retraso en la digitalización táctil para que la mira responda de forma instantánea al deslizar el dedo.

💡 Impacto: Disminuye el delay de respuesta táctil a nivel de sistema Android de 50ms a menos de 10ms.
BREVENT / SHIZUKU
settings put secure long_press_timeout 250 && settings put system touch_blocking_period 0

Forzar Tasa de Refresco Máxima (120Hz / 90Hz)

Evita que el sistema reduzca dinámicamente los Hz de la pantalla a 60Hz cuando abres juegos como Free Fire o PUBG.

💡 Impacto: Elimina los micro-tirones y fija la fluidez máxima sostenida de la pantalla.
BREVENT / SHIZUKU
settings put system peak_refresh_rate 120.0 && settings put system min_refresh_rate 120.0

⚡ 2. GESTIÓN DE MEMORIA RAM Y CACHÉ

Sin Root / Brevent

Limpieza Profunda de Caché y Mantenimiento

Fuerza la recolección de basura del sistema y vacía cachés de aplicaciones pesadas acumuladas en memoria.

💡 Impacto: Libera entre 500MB y 1.5GB de RAM activa para el juego.
BREVENT / SHIZUKU
pm trim-caches 999999999999MB && cmd activity idle-maintenance

Desactivar Procesos Fantasma y Doze Mode

Evita que Android congele el proceso del juego o suspenda la red cuando el teléfono se calienta levemente.

💡 Impacto: Prioridad alta al procesador gráfico evitando cierres inesperados.
BREVENT / SHIZUKU
dumpsys deviceidle disable && settings put global fstrim_mandatory 1

Desactivar Escaneo Wi-Fi para Reducir Ping

Detiene el escaneo en segundo plano de redes Wi-Fi que causa saltos de ping (Spikes) durante las partidas.

💡 Impacto: Mantiene la latencia de red estable y sin picos altos.
BREVENT / SHIZUKU
settings put global wifi_scan_always_enabled 0

🔥 3. CPU, GPU Y KERNEL TUNING

KernelSU / Magisk / Root

Spoof Infinix GT 20 Pro (Desbloquear 120 FPS)

Engaña a los servidores del juego haciendo pasar tu dispositivo por un gama alta enfocado en gaming para desbloquear opciones gráficas ultra.

💡 Impacto: Desbloquea el selector de 120 FPS e Ultra HD sin alterar la partición `/system`.
ROOT EXEC
resetprop ro.product.model 'Infinix GT 20 Pro' && resetprop ro.product.brand 'Infinix' && resetprop ro.product.manufacturer 'Infinix' && resetprop ro.product.system.model 'Infinix GT 20 Pro' && resetprop ro.product.vendor.model 'Infinix GT 20 Pro'

Governor de CPU Performance (Frecuencia Sostenida)

Evita la bajada de frecuencia del procesador cuando la CPU detecta carga alta, manteniendo todos los núcleos activos.

💡 Impacto: Maximiza el rendimiento bruto del procesador y elimina bajones de FPS en batallas intensas.
ROOT EXEC
echo performance > /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor

Ajuste de Swappiness / Prioridad de RAM Real

Obliga al Kernel de Linux a almacenar el juego en la memoria RAM ultra rápida en lugar de la memoria ZRAM/Swap en almacenamiento interno.

💡 Impacto: Tiempos de carga más rápidos y tasa de cuadros por segundo súper estable.
ROOT EXEC
sysctl -w vm.swappiness=10 && sysctl -w vm.vfs_cache_pressure=50

Vaciado Directo de Buffers de Kernel

Pone en cero el espacio de búfer de la memoria RAM del sistema antes de iniciar una sesión de juego exigente.

💡 Impacto: Inicia el juego con el 100% de los recursos disponibles.
ROOT EXEC
sync; echo 3 > /proc/sys/vm/drop_caches

❓ Preguntas Frecuentes (FAQ)

¿Los comandos Sin Root pueden dañar mi dispositivo Android?
No. Los comandos ejecutados vía ADB/Shizuku/Brevent modifican únicamente la capa de configuración de usuario (`settings put` y `cmd`). No alteran archivos del sistema y se restablecen o pueden revertirse fácilmente.
¿Por qué es recomendable usar Brevent o Shizuku?
Permiten enviar instrucciones avanzadas al sistema operativo sin necesidad de desbloquear el bootloader ni perder la garantía del teléfono. Es el método más seguro para mejorar la respuesta táctil y memoria.
¿Qué ventaja ofrece el Spoofing de modelo con Root?
Muchos juegos limitan los FPS según la lista de modelos detectados por el servidor. Al modificar la propiedad `ro.product.model` mediante `resetprop`, el juego reconoce tu dispositivo como una consola gamer y habilita los 120 FPS.
